# License Decision Notes

The current package is staged with a conservative license placeholder and Zenodo metadata set to `cc-by-nc-4.0` as a publication-friendly starting point.

Review before public release because the source materials describe Inspector Roofing Protocols(TM) as proprietary. A clean approach may be split licensing:

- App code: MIT or Apache-2.0.
- Paper: CC BY-NC 4.0.
- Trademarks and proprietary methodology: all rights reserved.
- Raw source manuscripts: keep private unless they are intentionally part of the public standard.

This is not legal advice. It is a publication planning note.
